# Priyanshu Kumar | Portfolio Website

A fully responsive personal portfolio website built with HTML, CSS and JavaScript.

**Live site:** https://priyanshu82004.github.io/portfolio/

## Sections
- About Me and Education
- Skills (filterable, animated bars)
- Experience
- Projects (filter and details popup)
- Certifications
- Contact form with validation

## Features
- Responsive layout for mobile, tablet and desktop
- Dark and light mode (saved in the browser)
- Typing effect, scroll progress bar, active menu highlight
- Animated counters and skill bars
- Project details modal
- Contact form that opens the email app

## Tech used
HTML5, CSS3, JavaScript (vanilla)

## Run locally
Download the repository and open `index.html` in a browser.
